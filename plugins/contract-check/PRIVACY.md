# Privacy Policy / プライバシーポリシー

最終更新日: 2026年10月6日

このプライバシーポリシーは、Claude 向けプラグイン **contract-check**（以下「本プラグイン」）における情報の取り扱いを説明します。

## 開発者が収集する情報

**ありません。** 本プラグインの開発者は、利用者の情報を受け取るサーバーやサービスを運営していません。利用状況の計測（アナリティクス）やトラッキングも行いません。

## 本プラグインが読む情報

利用者が Claude に渡した契約書を、Claude が利用者の環境の中で読みます。これらには氏名・住所・金額などの個人情報が含まれることがあります。読んだ内容が開発者に送られることはありません。

Claude との会話やファイルの取り扱いには、Anthropic のプライバシーポリシー（https://www.anthropic.com/legal/privacy）が適用されます。

## 外部への通信

本プラグインのスクリプトは、法令・資料を取得するために次の公的機関のサービスにだけ接続します。送るのは取得条件だけで、契約書の内容は送りません。

- e-Gov法令API（`https://laws.e-gov.go.jp`、デジタル庁）: 法令名・条番号・検索語

これらのサービスでの情報の取り扱いは、各機関のポリシーに従います。

- e-Gov: https://www.e-gov.go.jp/privacy-policy

## 利用者のコンピュータに保存するもの

レビュー・作成の結果（Markdown・HTML）は、利用者が指定した場所に保存されます。キャッシュや設定ファイルは作りません。

## 変更

このポリシーを変更する場合は、このファイルを更新し、最終更新日を改めます。変更履歴は GitHub のコミット履歴で確認できます。
