# contract-check

日本語の契約書を、条項の中身まで踏み込んでレビューする [Claude Code](https://claude.com/claude-code) プラグインです。

## インストール

```
/plugin marketplace add Ebi-lock/work-contract-check
/plugin install contract-check@work-contract-check
```

## 使い方

契約書のファイルを渡して話しかけるだけです。PDF・Word・テキスト・貼り付けのいずれにも対応します。

```
業務委託契約書.pdf をチェックして
この契約、このまま締結して大丈夫？
不利な条項はない？
抜けている条項があれば教えて
雇用契約書をレビューして。私は労働者側です
```

最初に**どちらの立場でチェックするか**（受注者側／発注者側／中立）を確認します。「不利」は立場が決まらないと判定できないためです。

## 出力

1. **会話** — サマリーと🔴高リスクの指摘（🔴が5件を超えるときは上位5件）
2. **Markdownレポート** — 全文。差分管理・再編集用の原本
3. **HTMLレポート** — 閲覧・共有・印刷用。単一ファイルで外部依存がないため、そのままメール添付でも開けます

HTMLレポートには次が付きます。

- リスク階級（🔴高／🟡中／🔵低／⬜欠落）で色分けしたカード
- 階級での絞り込みボタン（🔴だけ表示して交渉の場で使う、といった読み方ができます）
- 修正条文案のコピーボタン（そのまま相手へのメールに貼れます）
- 目次とスクロール追従、印刷レイアウト、ダークモード、スマホ幅対応

## 指摘の書き方

抽象論で終わらせず、その契約の金額・期間を当てはめた具体的なシナリオまで書きます。

> **[R-02] 第12条（損害賠償） 🔴 高**
>
> > 第12条 乙は、本契約に関して甲に損害を与えた場合、その一切の損害（逸失利益、第三者からの請求に基づく損害を含む）を賠償する。
>
> - **問題**: 賠償額に上限がなく、通常は除外される逸失利益・間接損害まで含む。しかも甲側の賠償義務は定められておらず片面的。
> - **起こり得る事態**: 委託料60万円の案件で、納品物の不具合により甲のECサイトが1日停止した場合、その日の売上相当額（数百万円規模）を逸失利益として請求され得る。受託金額と賠償リスクが釣り合わない。
> - **法的根拠**: 民法416条の通常損害・特別損害の区分を契約で上書きしている状態。消費者契約でないため無効にはならず、そのまま効力を持つ。
> - **修正案**: 「乙の賠償責任は、故意又は重過失による場合を除き、本件業務の委託料相当額を上限とし、逸失利益及び間接損害を含まないものとする。甲についても同様とする。」

**書かれていない条項**も同じ粒度で指摘します。「検収条項がありません」だけでは動けないので、「納品後いつまでも『まだ確認中』と言われて報酬支払期日が起算されない」「どこまで直せば完成なのか決まらず無限に修正対応が続く」まで書きます。

## 対応する契約類型

| 類型 | 上乗せでチェックする主な観点 |
|---|---|
| 業務委託・請負・準委任・SES | 請負／準委任の実態判定、偽装請負・労働者性、取適法／フリーランス法の適用と禁止行為、検収、契約不適合責任、競業避止 |
| 雇用契約・労働条件通知書 | 労基法15条・労基則5条の明示事項（2024年4月追加の3項目を含む）、労基法上そもそも置けない条項、固定残業代の要件、無期転換、解雇 |
| 秘密保持（NDA） | 片務／双務、秘密情報の定義、5つの例外規定、開示できる範囲、残留記憶条項 |
| 売買・継続的取引基本契約 | 基本契約と個別契約の優先順位、所有権移転と危険負担、商法526条の検査・通知義務、継続的契約の解約制限 |
| 賃貸借（不動産・動産・リース） | 普通借家／定期借家の判定、借地借家法30条・37条に反して無効になる特約、敷金・原状回復、自力救済条項 |
| ライセンス・SaaS・共同開発 | 許諾範囲の5要素、定型約款の変更条項、SLA、入力データの学習利用、共有特許・共有著作権の行使 |

どの類型でも、全契約共通のチェックポイント（片面性の検出、損害賠償、解除、秘密保持、知財、支払条件、一般条項、欠落16項目）と突き合わせます。

## 法令の確認

条文に言及するときは、記憶で書かずに取得します。

```bash
python3 scripts/egov.py laws                  # 頻出法令のID一覧
python3 scripts/egov.py search 労働者派遣      # 法令名から law_id を探す
python3 scripts/egov.py article 民法 641       # 条文を取得（枝番は 398-2）
python3 scripts/egov.py keyword 秘密保持       # 条文本文の全文検索
```

APIキーは不要です。出力には**最終改正施行日**が含まれるので、まだ施行されていない条文を見ていないか確認できます。

参照ファイルで引用している88か所の条文番号は、e-Gov法令APIで実在を検証済みです。
下請法は2025年改正で**取適法（中小受託取引適正化法）**に改称され条番号も繰り上がったため、旧番号との対応表を `references/legal-sources.md` に置いています。

ネットワークが使えない場合は、推測で条文を書かずに「条文未確認」と明記し、確認すべき法令名と条番号だけを示します。誤った条文番号を添えた指摘は、指摘がないより有害だからです。

## 構成

```
skills/contract-check/
├── SKILL.md                      進め方、指摘の書き方、リスク階級の基準
├── scripts/
│   ├── egov.py                   e-Gov法令API v2 のCLI
│   └── render_report.py          MarkdownレポートをHTMLに変換
├── references/
│   ├── checkpoints-common.md     全契約共通の不利条項パターンと欠落リスク一覧
│   ├── legal-sources.md          法令の調べ方、強行規定／任意規定の区別
│   ├── report-format.md          レポートテンプレートと粒度の指針
│   └── type-*.md                 契約類型6種それぞれの上乗せ項目
└── evals/
    ├── evals.json                テストケースと16項目の判定基準
    └── files/                    不利条項を仕込んだサンプル契約書
```

## 動作要件

- Python 3.8 以上（標準ライブラリのみ。追加パッケージのインストールは不要です）
- ネットワーク接続（法令条文の取得に使用します）

PDF・Wordの契約書を読むには、Claude Code 側の `pdf` / `docx` スキルを使います。画像PDF（スキャン）の場合はOCRが必要になる旨をお伝えします。

## レポートを単体で変換する

レビューを実行せずに、既存のMarkdownレポートをHTMLに変換することもできます。

```bash
python3 scripts/render_report.py 契約書チェック結果_業務委託契約書_20260921.md
python3 scripts/render_report.py report.md -o out.html --title "業務委託契約レビュー"
```

## 通信と保存するファイル

- **通信先**: `scripts/egov.py` が e-Gov法令API（`https://laws.e-gov.go.jp`）に法令名・条番号・検索語を送って条文を取得します。APIキーは不要です。それ以外の外部サービスには接続しません
- **契約書の内容は外部に送りません**。スクリプトが送るのは法令の検索条件だけです
- **書き出すファイル**: Markdown と HTML のレポートを、指定した出力先に保存します。キャッシュや設定ファイルは作りません

## 免責

**出力は法的助言ではありません。** 弁護士に相談する前の一次スクリーニングとして使ってください。

- 事実関係や取引の経緯によって結論は変わります。レポートは契約書の記載内容だけに基づく一般的な指摘です
- 報酬を得て法律事件に関する鑑定・代理・仲裁・和解その他の法律事務を扱うことは、弁護士法72条により弁護士に限られています。本プラグインはその代替ではありません
- 高額・長期拘束・知財の全面譲渡・個人保証・専属的な競業避止を含む契約では、必ず弁護士の確認を受けてください
- 出力内容に起因する損害について作者は責任を負いません

契約書には氏名・報酬額・取引先名が含まれます。レビュー対象の契約書と出力レポートは、リポジトリにコミットしないでください。

フリーランスとして受注する契約でお困りの場合、第二東京弁護士会が運営する「[フリーランス・トラブル110番](https://freelance110.mhlw.go.jp/)」（厚生労働省委託事業）で無料相談ができます。

## 出典

法令の条文・法令名・施行日は [e-Gov法令検索](https://laws.e-gov.go.jp/)（デジタル庁）の[法令API Version 2](https://laws.e-gov.go.jp/api/2/swagger-ui/) から取得しています。

> 出典：e-Govポータル（https://www.e-gov.go.jp）

e-Gov のコンテンツには[公共データ利用規約（第1.0版）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)（PDL1.0）が適用されます。
本プラグインは取得した法令データを、可読性のために整形して出力します（条文そのものの改変は行いません）。
レポート内の指摘・評価・修正条文案は本プラグインによる加工物であり、国や府省等の見解ではありません。

- [厚生労働省 労働契約等解説セミナー（労働契約ポータルサイト）](https://roukeiseminar.mhlw.go.jp/rules.html) — 雇用契約の行政解釈と裁判例
