# 全契約共通チェックポイント

契約類型を問わず効いてくる観点。各項目は「**危険な書きぶり**（現物でよく見る形）／**妥当な水準**／**なければ何が起きるか**」で構成してある。契約書の該当条項を引用したうえで、この基準に照らして判定する。

## 1. 形式・成立要件

| 観点 | 見るところ |
|---|---|
| 当事者の特定 | 商号・住所・代表者名が登記と一致するか。個人事業主なら屋号だけでなく個人名があるか。グループ会社のどの法人か曖昧な記載（「〇〇グループ」等）は請求先が定まらず危険 |
| 契約日・効力発生日 | 両方あるか。遡及適用（「本契約は◯年◯月◯日に遡って効力を生じる」）がある場合、遡及期間中の行為に新条項が適用されることを認識しているか |
| 別紙・仕様書の参照 | 「詳細は別紙のとおり」と書かれた別紙が実在するか。**存在しない別紙への参照は頻出の欠陥**で、業務範囲が確定しない |
| 優先順位条項 | 本契約・個別契約・仕様書・発注書が矛盾したときどれが優先するか。定めがないと矛盾時に解釈紛争になる |
| 印紙 | 紙で締結する課税文書か（請負契約＝2号文書、継続的取引の基本契約＝7号文書）。貼付義務者と負担者の記載。電子契約なら不課税 |
| 署名・記名押印 | 代表者名義か。支店長・部長名義の場合、代理権の有無を確認する必要がある |

## 2. 片面性の検出

最も効率よく不利条項を見つけられる観点。条項ごとに「主語が甲だけになっていないか」を見る。

チェックする典型:

- 解除権が一方にだけある／無催告解除できるのが一方だけ
- 損害賠償義務が一方にだけ課されている、または賠償上限が一方にだけ設定されている
- 秘密保持義務が一方にだけ課されている（情報が双方向に流れるのに片務）
- 反社会的勢力の排除条項で、表明保証するのが一方だけ
- 契約内容・仕様・報酬の変更権が一方に留保されている
- 権利義務の譲渡禁止が一方にだけ課されている
- 遅延損害金の定めが一方の債務にだけある

片面であること自体は直ちに違法ではないが、交渉材料として最も通りやすい。「双方向にする」という修正案は相手も飲みやすい。

## 3. 損害賠償・免責

**危険な書きぶり**

- 「一切の損害を賠償する」— 上限なし
- 「逸失利益、間接損害、特別損害、第三者からの請求を含む」— 範囲が無限定
- 賠償義務が一方にのみ、または上限が一方にのみ設定されている
- 免責条項が「甲は一切の責任を負わない」と包括的（故意・重過失まで免責する条項は民法上無効と解される余地があるが、条項としては残る）
- 「違約金として金◯◯円を支払う」— 損害額の立証不要で確定するため、実損より高額なら不利。民法420条により裁判所は原則として増減できない

**妥当な水準（受注者側の目安）**

- 賠償上限＝当該業務の委託料相当額、または過去12か月に受領した対価の総額
- 逸失利益・間接損害・特別損害を除外
- 故意・重過失の場合は上限を外す（相手が飲みやすい落としどころ）
- 責任追及期間の制限（引渡し／役務提供完了から6か月〜1年）

**なければ**: 民法416条の原則によることになり、通常損害に加え「予見すべきであった特別の事情による損害」まで賠償範囲に入る。上限がないため、受領額を大きく超える賠償を負う可能性が残る。

**関連法令**: 民法415条（債務不履行による損害賠償）、416条（損害賠償の範囲）、420条（賠償額の予定）、消費者契約法8条・9条（相手が消費者の場合の無効規定）

## 4. 解除・中途解約

**危険な書きぶり**

- 「甲は、必要があると認めるときは、何らの催告なく本契約を解除できる」— 無催告・無条件・片面
- 解除事由に「甲が不適当と判断したとき」等の主観的・抽象的要件が入っている
- 中途解約時の既履行部分の報酬・費用精算の定めがない
- 解除された側に違約金・損害賠償義務があるのに、解除した側の補償義務がない
- 軽微な違反でも直ちに解除できる（「本契約のいずれかの条項に違反したとき」に催告なし）

**妥当な水準**

- 債務不履行解除は相当期間（14日〜30日）を定めた催告を前置
- 無催告解除は、支払停止・破産申立て・手形不渡り・差押え・解散・反社該当など客観的に判定できる事由に限定
- 任意解約には予告期間（1〜3か月）と既履行分の精算を定める
- 解除権は双方に置く

**なければ**: 民法541条以下の法定解除しか使えず、「相手の対応が悪いから抜けたい」といった理由では抜けられない。逆に任意解約条項がないのに相手が一方的に離脱した場合は、損害賠償請求が必要になり回収が難しい。請負では民法641条により注文者はいつでも解除できる（損害賠償は要する）ため、受注者側は精算条項の有無を必ず見る。

**関連法令**: 民法541条〜543条、民法628条（やむを得ない事由による解除）、民法641条（注文者の解除権）、民法651条（委任の解除）

## 5. 契約期間・更新

| 見るところ | 危険な水準 |
|---|---|
| 自動更新条項 | 更新拒絶の申入れ期限が長い（6か月前など）。短期契約なのに長い予告期間は実質的な長期拘束 |
| 更新拒絶の要件 | 「相手方が同意した場合に限り更新しない」等、事実上解約できない構造 |
| 存続条項 | 秘密保持・知財・損害賠償・管轄が契約終了後も残るか。範囲と期間が明示されているか |
| 契約終了後の義務 | 引継ぎ義務・データ返還・利用停止の範囲が過大でないか（無償・無期限の引継ぎ義務は不利） |

**なければ**: 期間の定めがない継続的契約は、相当期間の予告で解約できるとするのが判例の考え方だが、「相当期間」が争いになる。存続条項がないと、契約終了と同時に秘密保持義務も消えたと主張される余地が生じる。

## 6. 秘密保持

**危険な書きぶり**

- 秘密情報の定義が無限定（「本契約に関連して知り得た一切の情報」で、書面明示の要件も秘密表示の要件もない）— 何が秘密か特定できず、事実上すべての行動が違反リスクになる
- 例外規定がない。最低限、①受領前から保有 ②公知 ③第三者から正当に取得 ④独自開発 ⑤法令・裁判所の命令による開示 の5つが必要
- 義務期間が「無期限」— 管理コストが永久に残る
- 目的外使用の禁止はあるが、契約終了時の返還・廃棄の定めがない
- 違反時の違約金が高額に固定されている

**妥当な水準**: 書面・電磁的記録で秘密である旨を明示したものに限定（口頭開示は30日以内に書面で確認）、5つの例外規定、期間は契約終了後3〜5年、返還または廃棄と廃棄証明。

**なければ**: 不正競争防止法上の「営業秘密」として保護されるには秘密管理性・有用性・非公知性の3要件が必要で、契約上の定めがないと秘密管理性の立証が難しくなる。

**関連法令**: 不正競争防止法2条6項（営業秘密の定義）、同2条1項4号〜10号

## 7. 知的財産権

**危険な書きぶり（受注者側で特に注意）**

- 「本件業務に関し乙が作成した一切の成果物の著作権（著作権法27条及び28条の権利を含む）は、甲に帰属する」＋**既存著作物・汎用モジュールの留保がない**— 自社のライブラリやノウハウまで持っていかれ、以後の案件で使えなくなる
- 「乙は著作者人格権を行使しない」だけがあり、対価の定めがない
- 特許を受ける権利まで無償で譲渡される（職務発明との整合も要確認）
- 譲渡の時期が「作成の時」になっており、報酬未払いでも権利だけ移転する
- 成果物の第三者権利非侵害を無限定に保証させられている（OSS・生成AI利用時に特に危険）

**妥当な水準**

- 譲渡範囲を「本件成果物のうち、本件業務のために新たに作成した部分」に限定
- 乙が従前から保有する著作物・汎用的なプログラム・ノウハウは乙に留保し、甲には利用許諾で対応
- 権利移転時期を報酬全額の支払い完了時とする
- 非侵害保証は「乙の知る限り」を付す、または賠償上限を設ける

**なければ**: 著作権法上、著作権は創作した者（受注者）に原始的に帰属する。発注者側は著作権を取得できず、成果物の改変（翻案）すらできないおそれがある。発注者側のレビューではこの欠落は重大な指摘になる。

**関連法令**: 著作権法15条（職務著作）、17条、21条〜28条、59条（著作者人格権の一身専属性）、特許法35条（職務発明）

## 8. 個人情報・データ

- 個人データの取扱いを委託する場合、委託元には委託先の監督義務がある（個人情報保護法25条）。監督の根拠となる条項（再委託の制限、安全管理措置、報告義務、監査権）があるか
- 漏えい時の報告義務・費用負担の定めがあるか。賠償上限の対象外とされていないか（個人情報漏えいは賠償上限の例外にされがちなので、受注者側は要チェック）
- 外国にある第三者への提供（海外サーバ・海外の再委託先）が想定される場合の同意・情報提供の手当て
- 契約終了後のデータ返還・削除の期限と方法
- 生成AI・クラウドサービスへの入力可否が定められているか（近年の紛争の火種）

**関連法令**: 個人情報保護法25条（委託先の監督）、26条（漏えい等の報告）、27条・28条（第三者提供・外国にある第三者への提供）

## 9. 支払条件

| 見るところ | 危険な水準 | 法令上の上限 |
|---|---|---|
| 支払期日 | 「検収完了後、甲が指定する日」など起算点が不明確 | 下請取引・フリーランス取引では**受領日から60日以内**（取適法3条、フリーランス法4条） |
| 支払サイト | 月末締め翌々月末払い（実質60日超） | 上記に抵触するおそれ |
| 手形・電子記録債権 | 満期が長い（120日など） | 支払手段として認められるか、割引困難でないか |
| 振込手数料 | 「乙の負担とする」 | 下請取引では発注者負担が原則（一方的な減額に当たり得る） |
| 遅延損害金 | 定めなし、または一方にのみ | 商事法定利率／約定利率。14.6%を超える設定は相場外 |
| 報酬の減額 | 「甲は合理的な理由により報酬を減額できる」 | 下請取引・フリーランス取引では**減額の禁止**（取適法5条1項3号、フリーランス法5条1項2号） |
| 消費税・実費 | 内税/外税、交通費・機材費の負担が明示されているか | — |

**なければ**: 支払期日の定めがないと民法412条の履行遅滞の判定が曖昧になる。取適法・フリーランス法の適用がある取引では、支払期日の明示自体が法律上の義務であり、不記載は発注者側の法令違反になる。

## 10. 一般条項

| 条項 | 危険な書きぶり | なければ起きること |
|---|---|---|
| 合意管轄 | 相手方本店所在地の裁判所の**専属的**合意管轄 | 民訴法の原則により被告住所地等になり予測が立たない。遠隔地指定は実質的に訴訟を断念させる効果を持つので、距離と訴額を踏まえて指摘する |
| 準拠法 | 外国法指定（相手が外国法人の場合） | 国際私法により決まり不確実 |
| 権利義務の譲渡禁止 | 一方にのみ課す。債権譲渡まで全面禁止（資金調達の妨げになる） | 相手方が契約上の地位を第三者に移転し、見知らぬ相手と取引することになる |
| 反社条項 | 片面的、または表明保証のみで解除権がない | 反社関与が判明しても契約を切れない |
| 不可抗力 | 定めなし、または免責の対象が一方のみ | 天災・感染症・戦争等で履行不能になった場合の責任分配が民法の危険負担の一般則に委ねられる |
| 契約内容の変更 | 「甲は必要に応じ本契約の内容を変更できる」 | 一方的変更権は極めて不利。書面による双方合意を要件とすべき |
| 協議条項 | — | なくても実害は小さいが、あると交渉の足がかりになる |
| 通知条項 | 通知先・方法（書面／メール）の定めなし | 解除通知が到達したかで争いになる |
| 完全合意条項 | 事前のやりとりや見積前提が全部切り捨てられる | 口頭・メールでの合意事項が効力を失う。前提条件は本文か別紙に落とす |

## 11. 不記載だと危ない条項一覧

欠落チェックはこの一覧と突き合わせる。**「ない」ことに気づくのは読んでいて最も難しい**ので、必ず機械的に照合する。

| 条項 | 不記載で起きること | 優先度 |
|---|---|---|
| 業務範囲・成果物の特定 | 「これも契約に含まれるはず」と際限なく作業が追加される | 🔴 |
| 報酬額・算定方法 | 追加作業分の対価が回収できない | 🔴 |
| 支払期日 | 支払いが遅延しても遅滞責任を問いにくい／法令違反 | 🔴 |
| 検収（期間・基準・みなし合格） | 検収が終わらず支払いが起算されない、修正が無限に続く | 🔴 |
| 契約不適合責任（期間・範囲） | 引渡し後いつまでも無償対応を求められる | 🔴 |
| 知的財産権の帰属 | 発注者は成果物を改変・再利用できない／受注者は既存資産を失う | 🔴 |
| 損害賠償の上限 | 受領額を大きく超える賠償リスクが残る | 🔴 |
| 秘密保持 | 営業秘密としての保護を主張しにくい | 🟡 |
| 再委託の可否 | 想定外の第三者が業務に関与する／再委託できず履行不能 | 🟡 |
| 中途解約・精算 | 抜けられない、または既履行分が回収できない | 🟡 |
| 権利義務の譲渡禁止 | 相手方が入れ替わる | 🟡 |
| 反社排除 | 反社関与が判明しても解除できない | 🟡 |
| 存続条項 | 契約終了で秘密保持義務等が消えたと主張される | 🟡 |
| 合意管轄 | 紛争時の裁判所が予測できない | 🟡 |
| 不可抗力 | 不可抗力時の責任分配が不明確 | 🔵 |
| 通知の方法 | 解除通知等の到達で争いになる | 🔵 |
