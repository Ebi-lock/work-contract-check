# 業務委託・請負・準委任

`checkpoints-common.md` に加えて確認する項目。実務で最も件数が多く、法令規制も濃い類型。

## 0. 最初に判定する3つ

### (1) 請負か準委任か

表題ではなく中身で決まる。報酬が「成果物の完成」に結びついていれば請負、「業務の遂行」に結びついていれば準委任。

| | 請負 | 準委任 |
|---|---|---|
| 報酬の対象 | 仕事の完成 | 事務の処理 |
| 契約不適合責任 | あり（民法559条→562条〜) | なし（善管注意義務違反の債務不履行で処理） |
| 注文者の任意解除 | いつでも可。損害賠償を要す（民法641条） | 各当事者がいつでも可。不利な時期の解除は賠償（民法651条） |
| 中途終了時の報酬 | 可分な部分について割合請求（民法634条） | 既にした履行の割合に応じ請求（民法648条3項） |

**危険なパターン**: 準委任と称しながら「乙は本件成果物を完成させ、甲の検収に合格しなければならない」と書いてある（実質請負なのに受注者が完成義務を負い、かつ請負の割合報酬規定も外されている）。逆に請負と称しながら「乙は甲の指示に従い作業する」となっている場合は次の(2)へ。

### (2) 偽装請負・労働者性のリスク

契約形式が業務委託でも、実態が指揮命令下の労務提供なら労働者派遣法・職業安定法違反、または労働契約とみなされる。次の記載があれば指摘する:

- 「乙は甲の指示に従って業務を遂行する」「甲の担当者の指揮監督のもとで」
- 勤務時間・勤務場所の指定（「甲の就業時間に準じる」「甲の事業所に常駐する」）
- 始業終業時刻の報告、出退勤管理、有給に相当する休暇規定
- 業務従事者の指名権・交代要求権が甲にある
- 報酬が時間単価で、成果と無関係に稼働時間で決まる（それ自体は違法でないが、他の要素と重なると労働者性を補強する）

**指摘の仕方**: 受注者側なら「労働者性が認められた場合、社会保険・残業代の問題が生じる一方、契約上は業務委託として保護が薄い中間状態になる」。発注者側なら「偽装請負として是正指導・派遣法違反のリスク。指揮命令に関する条項を削除し、業務の独立性を担保する記載に改める」。

**関連法令**: 労働者派遣法2条・4条、職業安定法44条、労働基準法9条

### (3) 取適法・フリーランス法の適用があるか

適用があると、契約書の記載事項そのものが**法律上の義務**になる。受注者側では保護規定を、発注者側では自社の法令違反リスクを見る。

**取適法（中小受託取引適正化法。旧「下請代金支払遅延等防止法」。2025年改正・2026年1月1日施行）** — 資本金または従業員数の区分で適用が決まる（2条8項・9項）:

| 取引類型 | 委託事業者 | 中小受託事業者 |
|---|---|---|
| 製造委託・修理委託・特定運送委託 | 資本金3億円超 | 個人・資本金3億円以下 |
| 同上 | 資本金1000万円超3億円以下 | 個人・資本金1000万円以下 |
| 情報成果物作成委託・役務提供委託 | 資本金5000万円超 | 個人・資本金5000万円以下 |
| 同上 | 資本金1000万円超5000万円以下 | 個人・資本金1000万円以下 |
| 製造委託等（従業員数基準・2026年改正で追加） | 従業員300人超 | 従業員300人以下 |
| 情報成果物作成委託・役務提供委託（同上） | 従業員100人超 | 従業員100人以下 |

適用がありそうなら必ず条文を取得して確認する: `python3 scripts/egov.py article 取適法 2`

**フリーランス法（特定受託事業者に係る取引の適正化等に関する法律、令和5年法律第25号、2024年11月1日施行）** — 発注者が事業者（従業員を使用する法人・個人）で、受注者が**従業員を使用しない個人または一人法人**の場合に適用。資本金要件はない。

### 適用がある場合に契約書でチェックすること

**明示義務（取適法4条／フリーランス法3条）** — 以下が契約書または発注書に書かれているか。書かれていなければ、発注者側の法令違反であり、受注者側にとっては後日の紛争リスク:

- 当事者の名称、業務委託をした日
- 給付の内容（業務の具体的内容・仕様）
- 給付を受領する期日／役務提供を受ける期日・期間
- 給付を受領する場所
- 検査をする場合はその検査完了期日
- 報酬（代金）の額または算定方法
- 支払期日
- 現金以外の支払手段を用いる場合はその内容
- 原材料等を有償支給する場合はその品名・数量・対価・引渡期日・決済方法

**禁止行為（取適法5条）** — 契約条項として以下が書き込まれていないか。「合意があれば適法」にはならない点が重要で、**契約書に書いてあっても違反は違反**:

1. 受領拒否（5条1項1号）
2. 支払遅延。支払期日は受領日から起算して60日以内に定めなければならない（3条）。期日までに支払わないことが5条1項2号違反
3. 代金の減額（5条1項3号）— 「甲は合理的理由により減額できる」型の条項は直撃する
4. 返品（5条1項4号）
5. 買いたたき（5条1項5号）
6. 物の購入強制・役務の利用強制（5条1項6号）
7. 報復措置（5条1項7号）
8. 有償支給原材料等の対価の早期決済（5条2項1号）
9. 経済上の利益の提供要請（5条2項2号）— 「協賛金」「センターフィー」型の条項
10. 不当な給付内容の変更・やり直し（5条2項3号）
11. **協議に応じない一方的な代金決定（5条2項4号。2026年改正で追加）**— 原材料費・労務費・エネルギーコスト高騰時に価格転嫁の協議を拒む行為

**フリーランス法の主な義務**: 明示義務（3条）、60日以内の支払期日設定（4条）、継続的業務委託における禁止行為（5条、取適法5条とほぼ同内容）、募集情報の的確表示（12条）、育児介護等への配慮（13条）、ハラスメント対策（14条）、**中途解除の30日前予告（16条）**。特に16条は契約書の解除条項と直接ぶつかるので必ず照合する。

## 1. 業務範囲・仕様

- 業務内容が「甲が別途指示する業務」のみで特定されていないか。**範囲が特定されていない契約は、追加作業の対価請求ができない**
- 仕様変更の手続き（変更要求書、見積の再提示、納期の再設定）が定められているか。定めがないと「軽微な変更」と称した無償の追加作業が積み上がる
- 成果物の定義（何をもって納品とするか。ソースコード、ドキュメント、設計書、権利処理済み素材）
- 業務従事者の要件（人数、スキル、常駐の有無）と交代の手続き

## 2. 納期・検収

| 見るところ | 危険な水準 | 妥当な水準 |
|---|---|---|
| 検収期間 | 定めなし／「甲が検査を完了するまで」 | 納品後10〜14営業日 |
| みなし合格 | なし | 「検収期間内に書面で不合格の通知がないときは、合格したものとみなす」 |
| 合格基準 | 「甲が満足する品質」等の主観的基準 | 仕様書との適合 |
| 不合格時 | 無制限の再納品義務、回数制限なし | 仕様不適合に限り、合理的期間内に修補 |
| 再検収 | 定めなし | 再納品後も同じ期間・基準で判定 |

**検収条項がない場合のリスク**: 報酬の支払期日が起算されず未払いが長期化する／「まだ検収が終わっていない」を理由に無限に修正を求められる／契約不適合責任の起算点が定まらない。これは受注者にとって最も実害の大きい欠落のひとつ。

## 3. 契約不適合責任（旧・瑕疵担保）

- 責任期間: 民法637条は「不適合を知った時から1年以内に通知」。契約で「引渡しから1年」「引渡しから6か月」に短縮するのが実務的な落としどころ。**「期間の定めなし」「引渡しから3年」は受注者に不利**
- 責任の範囲: 修補のみか、代金減額・損害賠償・解除まで認めるか
- 免責: 甲の指示・甲の支給材料に起因する不適合は免責されるか（民法636条の趣旨を明記しておく）
- 無償対応の範囲が「甲が要望する一切の修正」になっていないか（仕様不適合に限定すべき）

**関連法令**: 民法559条、562条〜564条、636条、637条

## 4. 再委託

- 全面禁止になっていないか（受注者側が実務を回せなくなる）
- 「甲の事前の書面による承諾」が必要な場合、承諾の判断期限が定められているか
- 再委託先の行為について乙が全責任を負う構造は通常だが、甲の指定した再委託先の場合も同じ扱いになっていないか
- 発注者側の視点では、再委託が無制限だと個人情報や秘密情報の管理が及ばない。個人情報保護法25条の監督義務との関係で指摘する

## 5. 報酬・費用

- 追加作業の単価・算定方法が定められているか
- 交通費・宿泊費・機材費・ライセンス費の負担
- 稼働時間の上限下限（精算幅）がある場合、その計算方法と超過時・不足時の扱い
- 契約期間途中で終了した場合の精算（請負なら民法634条、準委任なら648条3項が原則だが、契約で排除されていないか）

## 6. 競業避止・引抜き禁止

受注者側で特に確認する。**期間・地域・対象業務のいずれかが無限定なら🔴**。

- 「乙は、契約期間中および契約終了後、甲と同種の業務を第三者に対して行ってはならない」— 職業選択の自由を過度に制約し、公序良俗違反で無効と判断される余地はあるが、条項がある限り交渉・訴訟のコストは発生する
- 妥当な水準: 期間1〜2年、対象を「甲の顧客に対する同一業務」等に限定、代償措置の有無
- 引抜き禁止（従業員の勧誘禁止）は双方向になっているか

## 7. 成果物の第三者権利非侵害

- 「乙は、本件成果物が第三者の権利を侵害しないことを保証する」は、OSSや生成AIを使う開発では無限定な保証になり危険
- 妥当な水準: 「乙の知る限り」を付す、侵害クレーム時の対応手順（甲の通知義務、乙の防御権）を定める、賠償上限の対象に含める
- 発注者側では、この保証がないと侵害クレームを自社で受け止めることになるので、欠落として指摘する
