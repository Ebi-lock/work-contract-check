# 売買・継続的取引基本契約・OEM

`checkpoints-common.md` に加えて確認する項目。

## 1. 基本契約と個別契約の関係

- 基本契約と個別契約（注文書・注文請書）の**優先順位**が定められているか。定めがないと矛盾時に争いになる
- 個別契約の成立時期。「注文書の受領後◯営業日以内に諾否の通知をしない場合は承諾したものとみなす」型のみなし承諾条項は、売主側に🟡（意図せぬ受注が成立する）
- 最低購入数量（ミニマムコミット）があるか。未達時のペナルティ（差額支払い、単価遡及改定）は買主側に🔴になり得る

## 2. 目的物・数量・価格

- 仕様の特定方法（仕様書、サンプル、規格）
- 価格改定条項: 「甲は、市況の変動により売買代金を変更できる」型の一方的改定権は相手方に不利。**双方の協議による改定**にすべき。原材料費・エネルギーコストの高騰時に協議を拒む行為は取適法5条2項4号（2026年1月施行）に触れる可能性がある
- 数量の増減（±10%の許容など）と、増減時の価格調整

## 3. 所有権・危険負担

- **所有権移転時期**: 引渡時か、代金完済時か。売主側は代金完済時（所有権留保）が有利。買主側は転売や担保設定の観点から引渡時が有利
- **危険負担の移転時期**: 民法567条は引渡時に移転するとする。契約で前倒し（出荷時）されていないか
- 所有権移転と危険負担の移転時期がずれている場合、その間の保険の負担者
- 送付先が第三者（直送）の場合の引渡完了の判定

## 4. 検査・契約不適合責任

| 見るところ | 危険な水準 |
|---|---|
| 検査期間 | 定めなし／過度に短い（買主に不利）／過度に長い（売主に不利） |
| みなし合格 | なし |
| 不適合の通知期間 | 「引渡しから◯年」の長期設定は売主に不利。商人間売買では商法526条により**買主は遅滞なく検査し、直ちに通知**する義務がある（6か月の隠れた瑕疵の特則を含む）。契約で商法526条を排除していないか |
| 責任の内容 | 追完（修補・代替物引渡し）、代金減額、損害賠償、解除のどこまで認めるか |
| 引取義務 | 不適合品の引取費用・返送費用の負担者 |

商法526条の適用がある取引（当事者双方が商人）で契約が沈黙していると、買主側は通知期間を徒過して権利を失うリスクがある。買主側レビューでは必ず触れる。

## 5. 支払条件

`checkpoints-common.md` の「9. 支払条件」に加え:

- 相殺条項が一方的でないか
- 担保（保証金、連帯保証、根保証）の要求。個人が保証人になる根保証では**極度額の定めがないと無効**（民法465条の2）
- 期限の利益喪失条項の発動事由が広すぎないか
- 所有権留保がある場合、転売の可否と転売代金の扱い

## 6. 製造物責任・品質保証

- PL責任の負担者と、リコール費用の分担
- 品質保証の範囲（保証期間、保証対象外事由）
- 第三者からのクレーム対応の手順と費用負担
- 保険の付保義務（生産物賠償責任保険など）

## 7. 継続的契約特有

- **解約予告期間**: 長期間取引を継続してきた継続的契約では、判例上、正当な理由のない一方的解約が制限される場合がある。予告期間（6か月程度）と、相手方の投資回収への配慮があるか
- 最低取引期間・専属取引義務（他社との取引禁止）。独占禁止法上の拘束条件付取引・排他条件付取引に当たらないか
- 在庫・仕掛品・専用金型の契約終了時の買取義務
