# 賃貸借（不動産・動産・リース）

`checkpoints-common.md` に加えて確認する項目。借地借家法は**借主保護の強行規定**を多く含み、これに反して借主に不利な特約は無効になる（借地借家法30条、37条）。

## 1. 建物賃貸借で最初に判定すること

**普通借家か定期借家か。** これで借主の地位がまったく違う。

- 定期借家（借地借家法38条）には、①契約が**公正証書等の書面**（または電磁的記録）によること ②契約前に「更新がなく期間満了により終了する」旨を記載した**別個の書面**で説明すること、の要件がある。この事前説明書面がないと定期借家としては成立せず、普通借家になる
- 「定期借家契約」と題しながら事前説明書面の交付が確認できない場合は、その旨を指摘する
- 普通借家では、貸主からの更新拒絶・解約申入れに**正当事由**が必要（28条）。「貸主は◯か月前の通知により解約できる」という条項があっても、正当事由がなければ効力は否定される

## 2. 借地借家法に反して無効になる特約

見つけたら🔴で指摘する（条項として書かれていても効力がない）。

| 特約 | 根拠 |
|---|---|
| 借主からの更新請求を認めない（普通借家で） | 借地借家法30条 |
| 造作買取請求権の排除 | 33条。※これは任意規定で特約による排除が可能。排除されていること自体は違法ではないが借主に不利 |
| 賃料増減額請求権を一切排除する特約 | 32条。減額請求を排除する特約は無効（増額しない特約は有効） |
| 借主に不利な期間・解約の定め | 30条 |

## 3. 金銭関係

- **敷金**: 民法622条の2により、賃貸借終了・明渡し後に未払債務を控除して返還される。敷引き特約（一定額を返還しない）は、消費者契約の場合、消費者契約法10条により無効とされることがある（金額の相当性が判断基準）
- **原状回復**: 通常損耗・経年劣化は貸主負担が原則（民法621条）。「借主は通常損耗を含め原状に回復する」型の特約は、内容が具体的に明示され借主が認識していなければ効力が否定されやすい。国土交通省の原状回復ガイドラインとの乖離を確認する
- **更新料・礼金**: 金額と算定根拠、更新時の支払義務
- 賃料改定条項が一方的増額のみになっていないか
- 遅延損害金の利率（年14.6%を超える設定は相場外）

## 4. 使用・転貸・修繕

- 用途制限（居住専用、事務所使用可否）と違反時の効果
- 転貸・賃借権譲渡の可否。民法612条は賃貸人の承諾なき転貸を解除事由とするが、判例は**背信的行為と認めるに足りない特段の事情**があれば解除を認めない
- 修繕義務の分担。「一切の修繕は借主の負担とする」型は民法606条（賃貸人の修繕義務）を借主に不利に変更するもので、内容次第で🔴
- 借主による修繕（民法607条の2）の可否

## 5. 解除・明渡し

- 無催告解除条項。賃料の1回の遅滞で無催告解除できる条項は、判例上、信頼関係が破壊された場合に限定して解釈される
- **自力救済条項**（「貸主は借主の不在時に立ち入り、残置物を処分できる」）は違法。見つけたら🔴
- 明渡し時の残置物処理、鍵の返還、明渡し遅延損害金（賃料の2倍程度が相場、それを大きく超えるものは過大）
- 連帯保証人を立てる場合、**極度額の定めがないと個人根保証は無効**（民法465条の2）

## 6. リース・動産賃貸借

- ファイナンスリースか、レンタル（オペレーティングリース）か
- 中途解約の可否。ファイナンスリースでは中途解約不可＋残リース料一括支払いが通常だが、その金額の算定方法が明示されているか
- 物件の瑕疵についてリース会社が免責され、借主がサプライヤーに直接請求する構造になっているか（通常の設計だが、借主側には認識が必要）
- 契約終了時の返還・再リース・買取の選択肢と価格
- 危険負担、保険の付保義務
