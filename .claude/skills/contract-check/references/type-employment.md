# 雇用契約・労働条件通知書

`checkpoints-common.md` に加えて確認する項目。他の類型と決定的に違うのは、**労働基準法が強行法規**だという点。労基法の基準に達しない労働条件を定めた部分は無効になり、労基法の基準に置き換わる（労基法13条）。したがって「合意があるから有効」という論法が通らない。

条文にあたるときは e-Gov に加えて、**厚労省 労働契約ポータル** <https://roukeiseminar.mhlw.go.jp/rules.html> の解説と裁判例も参照する。行政解釈と裁判例の相場観がまとまっており、条文だけでは判断できない論点（更新期待、不利益変更の合理性、解雇の相当性）で役立つ。

- 労働契約の締結: <https://roukeiseminar.mhlw.go.jp/contract.html>
- 労働条件の変更: <https://roukeiseminar.mhlw.go.jp/alteration.html>
- 労働契約の終了: <https://roukeiseminar.mhlw.go.jp/expiration.html>
- 無期転換ルール: <https://roukeiseminar.mhlw.go.jp/indefinite.html>
- 裁判事例集: <https://roukeiseminar.mhlw.go.jp/law.html>

## 1. 明示事項（労基法15条1項、労基則5条）

**書面（または労働者が希望した場合はFAX・電子メール等）での明示が必要**なもの:

- 労働契約の期間
- 有期契約を更新する場合の基準（**通算契約期間または更新回数の上限がある場合はその上限**）
- 就業の場所および従事すべき業務（**変更の範囲を含む**）
- 始業・終業時刻、所定労働時間を超える労働の有無、休憩、休日、休暇、交替制の就業時転換
- 賃金の決定・計算・支払の方法、締切り・支払時期（昇給に関する事項は書面明示の対象外だが明示は必要）
- 退職に関する事項（**解雇の事由を含む**）

**定めをする場合に明示が必要**なもの: 退職手当、臨時の賃金・賞与・最低賃金額、食費・作業用品等の負担、安全衛生、職業訓練、災害補償、表彰・制裁、休職。

**無期転換申込権が発生する有期契約の更新時**には、無期転換申込みに関する事項と、転換後の労働条件も明示が必要。

> 「就業の場所及び従事すべき業務の**変更の範囲**」「更新回数・通算期間の**上限**」「**無期転換申込機会と転換後の労働条件**」の3点は2024年4月施行の追加項目で、古い雛形を使っている契約書ではまず抜けている。優先的に確認する。

不記載は労基法15条違反（30万円以下の罰金）であり、労働者側では「後から配置転換を命じられる範囲が読めない」「更新上限を後出しされる」というリスクにつながる。

条文で確認: `python3 scripts/egov.py article 労働基準法 15` / `python3 scripts/egov.py article 労働基準法施行規則 5`

## 2. 労基法上そもそも置けない条項

契約書に書かれていたら**その部分は無効**。見つけたら🔴で指摘する。

| 条項 | 根拠 |
|---|---|
| 「無断欠勤1日につき違約金◯円」「中途退職の場合は研修費◯円を支払う」等、損害賠償額をあらかじめ定める条項 | 労基法16条（賠償予定の禁止）。※実際に生じた損害の賠償請求まで禁じられるわけではない点は区別する |
| 前借金と賃金の相殺 | 労基法17条 |
| 強制貯蓄・社内預金の強制 | 労基法18条 |
| 「賃金から◯◯を控除する」（法定控除・労使協定に基づくもの以外） | 労基法24条（賃金全額払い） |
| 法定基準を下回る年次有給休暇、割増賃金率、休憩、法定労働時間 | 労基法13条により無効、法定基準に置換 |
| 国籍・信条・社会的身分による差別的取扱い | 労基法3条 |
| 性別を理由とする差別 | 男女雇用機会均等法5条・6条 |

## 3. 賃金

- **固定残業代（みなし残業）**: ①固定残業代に当たる部分の金額 ②それが何時間分の時間外労働に対応するか ③超過分を別途支払う旨、の3点が明示されているか。欠けると固定残業代として認められず、基本給全体を基礎に残業代を再計算されるリスクがある（使用者側で🔴）
- 最低賃金を下回っていないか（地域別最低賃金は毎年10月改定。固定残業代を除いた基本給部分で判定する）
- 割増率: 時間外25%以上、深夜25%以上、休日35%以上、月60時間超の時間外は50%以上（中小企業も2023年4月から適用）
- 賃金の支払日・締切日・支払方法（通貨払い・直接払い・全額払い・毎月1回以上・一定期日払いの5原則）
- 欠勤・遅刻控除の計算方法が賃金額を超える設計になっていないか

## 4. 労働時間・休日・休暇

- 所定労働時間が1日8時間・週40時間を超えていないか（特例事業を除く）
- 変形労働時間制・フレックス・裁量労働制を採用する場合、労使協定や就業規則の根拠が示されているか。**契約書に書いただけでは適法にならない**
- 時間外労働をさせるには36協定が必要。契約書に「時間外労働を命じることがある」とあるだけで36協定がなければ違法
- 年次有給休暇の付与日数が法定（6か月継続勤務・8割出勤で10日〜）を下回っていないか。年5日の時季指定義務への言及があるか
- 管理監督者（労基法41条2号）扱いにする場合、職務内容・権限・待遇が実態として伴うか。名ばかり管理職は残業代未払いにつながる

## 5. 期間の定め・更新・無期転換

- 有期契約の上限は原則3年（労基法14条。高度専門職・60歳以上は5年）
- 更新の有無と判断基準。「更新する場合がある」だけで基準が書かれていないのは明示義務違反
- 更新上限（通算5年以内など）を新設・短縮する場合は、事前に理由の説明が必要
- 通算5年を超えると無期転換申込権が発生する（労働契約法18条）。「無期転換申込権が発生しないよう5年到達前に雇止めする」旨の条項やクーリング目的の空白期間設定は、脱法的として問題になり得る
- 「労働者は無期転換申込権を放棄する」旨の事前放棄条項は無効と解されている
- 有期契約の期間途中の解雇は「やむを得ない事由」が必要（労働契約法17条1項）。無期より厳格である点に注意

## 6. 退職・解雇

- 解雇事由が列挙されているか（明示義務事項）。「その他会社が必要と認めたとき」等の包括条項のみは不適切
- 解雇予告30日または予告手当（労基法20条）への言及
- 解雇権濫用法理（労働契約法16条）— 客観的合理的理由と社会通念上の相当性がなければ無効
- 退職の申出期限。民法627条1項は期間の定めのない雇用で2週間前の申入れで終了するとしており、「退職は3か月前に申し出ること」という条項の拘束力には争いがある。労働者側には「法律上は2週間で退職できる可能性が高いが、条項がある以上トラブルになり得る」と幅を示して伝える
- 競業避止義務・秘密保持義務が退職後も及ぶ場合、期間・地域・職種の限定と代償措置があるか。無限定なら公序良俗違反で無効となる可能性が高いが、条項の存在自体が転職の障害になる
- 身元保証書を求める場合、期間（身元保証法により原則3年、最長5年）と**極度額の定め**があるか。極度額の定めがない身元保証契約は無効（民法465条の2）

## 7. その他

- 就業規則との関係: 契約条件が就業規則を下回る場合、就業規則の基準に引き上げられる（労働契約法12条）。「本契約に定めのない事項は就業規則による」とある場合、その就業規則が交付・周知されているか
- 労働条件の変更: 「会社は必要に応じ労働条件を変更できる」型の包括的変更権条項は、労働契約法8条・9条（合意によらない不利益変更の禁止）との関係で効力に疑義がある
- パート・有期契約の場合、正社員との不合理な待遇差の禁止（パートタイム・有期雇用労働法8条・9条）と待遇差の説明義務（14条）
- 副業・兼業の全面禁止条項は、裁判例上、本業への支障や競業がない限り制限できないと解されている
