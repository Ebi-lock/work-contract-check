# work-contract-check

日本の契約実務向け [Claude Code](https://claude.com/claude-code) プラグイン集です。

契約書を、**e-Gov法令検索から取得した現行条文を根拠に**点検します。
条番号を記憶で書かないこと、「条項があるか」ではなく「**どう書かれているか**」を判定することを設計の中心に置いています。

## 収録プラグイン

| プラグイン | 内容 |
|---|---|
| [contract-check](./plugins/contract-check) | 契約書を**レビューする**。自分にとって不利になり得る条項を原文引用・リスク階級・修正条文案つきで指摘し、本来あるべき条項が欠けている場合はその空白が生むリスクを通知する。結果はリスク階級で色分けしたHTMLレポートで出力 |

## インストール

Claude Code で次を実行します。

```
/plugin marketplace add Ebi-lock/work-contract-check
/plugin install contract-check@work-contract-check
```

あとは話しかけるだけです。

```
業務委託契約書.pdf をチェックして
この契約、このまま締結して大丈夫？
不利な条項はない？
抜けている条項があれば教えて
```

## 何をするか

`損害賠償の定めあり ✓` は何も言っていないに等しい、という考え方で作っています。
上限がなく間接損害まで含む賠償条項なのか、委託料を上限とする条項なのかで、負うリスクは桁違いに変わるからです。

- **中身まで判定する** — 各チェックポイントを「危険な書きぶり／妥当な水準／なければ何が起きるか」で定義し、賠償上限・支払サイト・検収期間・契約不適合責任の期間といった判定基準に具体的な数値を置いています
- **書かれていないことを探す** — 紛争の多くは禁止条項ではなく空白から生まれます。16項目の欠落チェックリストと機械的に照合し、「その空白を誰がどう突いてくるか」まで書きます
- **条文は取得して引用する** — 法令名も条番号も改正で変わります（下請法は2025年改正で取適法＝中小受託取引適正化法に改称され、条番号も繰り上がりました）。同梱の `egov.py` が e-Gov法令API v2 から現行条文を取得します
- **立場を確認してから判定する** — 「不利」は立場が決まらないと成立しないので、受注者側／発注者側／中立をレビュー前に確認します

対応する契約類型は、業務委託・請負・準委任／雇用・労働条件通知書／秘密保持（NDA）／売買・継続的取引基本契約／賃貸借／ライセンス・SaaS利用規約です。

## 免責

**出力は法的助言ではありません。** 弁護士に相談する前の一次スクリーニングとして使ってください。

- 事実関係や取引の経緯によって結論は変わります。レポートは契約書の記載内容だけに基づく一般的な指摘です
- 報酬を得て法律事件に関する鑑定・代理・仲裁・和解その他の法律事務を扱うことは、弁護士法72条により弁護士に限られています。本プラグインはその代替ではありません
- 法令の解釈が分かれる論点は断定せず幅を示す設計ですが、判断の正確性を保証するものではありません
- 高額・長期拘束・知財の全面譲渡・個人保証・専属的な競業避止を含む契約では、必ず弁護士の確認を受けてください
- 出力内容に起因する損害について作者は責任を負いません

契約書には氏名・報酬額・取引先名が含まれます。**レビュー対象の契約書と出力レポートをリポジトリにコミットしないよう**、`.gitignore` で除外しています。

## 出典

法令の条文・法令名・施行日は [e-Gov法令検索](https://laws.e-gov.go.jp/)（デジタル庁）の[法令API Version 2](https://laws.e-gov.go.jp/api/2/swagger-ui/) から取得しています。

> 出典：e-Govポータル（https://www.e-gov.go.jp）

e-Gov のコンテンツには[公共データ利用規約（第1.0版）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)（PDL1.0）が適用されます。
本プラグインは取得した法令データを、可読性のために整形して出力します（条文そのものの改変は行いません）。
レポート内の指摘・評価・修正条文案は本プラグインによる加工物であり、国や府省等の見解ではありません。

雇用契約のレビューでは、条文に加えて [厚生労働省 労働契約等解説セミナー（労働契約ポータルサイト）](https://roukeiseminar.mhlw.go.jp/rules.html) の行政解釈と裁判例を参照します。
改正沿革の確認には [日本法令索引](https://hourei.ndl.go.jp/)（国立国会図書館）を参照します。

## 動作要件

- Claude Code
- Python 3.8 以上（標準ライブラリのみ。追加パッケージのインストールは不要です）
- ネットワーク接続（法令条文の取得に使用します。APIキーは不要です）

ネットワークが使えない環境では、条文を推測で書かずに「条文未確認」と明記する設計にしています。
